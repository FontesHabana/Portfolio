PixelStudioCode is an Integrated Development Environment (IDE) designed for creating digital art through programming. At the heart of the project is PixelWallE, a programming language that translates code syntax into visual pixel art representations.

Developed with C# and Godot, the system features a real-time execution console and integrated technical documentation. Furthermore, it incorporates an image processing engine capable of transcoding conventional photographs into PixelWallE scripts, merging data analysis with creative design.
