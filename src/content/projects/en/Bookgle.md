Bookgle is a comprehensive semantic search solution designed for information management and retrieval in digital libraries. The core of the project implements vector similarity algorithms (TF-IDF) and prefix search optimizations, enabling precise and efficient content localization.

Developed as a full-stack system, the project integrates a robust C# backend responsible for data processing with a reactive interface built in React and Tailwind CSS, achieving a balance between algorithmic complexity and user experience.
