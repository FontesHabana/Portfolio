Sagrada is a competitive environment developed entirely in C# that challenges the visual and logical capabilities of the terminal. Based on 'Capture the Flag' mechanics, the project implements a local multiplayer system for up to four users within code-generated maze environments.

The development emphasizes clean architecture and the use of Spectre.Console to elevate the CLI user experience, demonstrating that algorithmic efficiency and solid logic can transform the simplicity of the console into a complex entertainment tool.
